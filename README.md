# Gym RPG: прототип страницы тренировки

Экспериментальный прототип, не часть приложения. Проверяет флоу тренировки как карты:
упражнения открываются по дереву, перед упражнением встречаются события (новый вес, делоад,
подбор веса, инвентарь), прогресс силы показан полоской до следующего веса.

Чистые HTML, CSS и JS без сборки.

## Запуск

```
python serve.py
```

Открыть http://localhost:5178. Сервер отдаёт файлы без кеша и слушает все интерфейсы,
так что с телефона в той же сети можно зайти по IP компьютера.

Состояние хранится в localStorage, сброс в меню «⋯» на карте.

## Что где

- `proto/` — прототип: `index.html`, `app.js`, `style.css`, картинки упражнений в `img/`.
- `art/` — исходники картинок от Nano Banana и скрипты подготовки:
  `prep.py` (кадр с зазором и прозрачный фон), `balance.py` (выравнивание по визуальному весу).
- `PROMPTS.md` — промпты и правила серии картинок.
- `icons.png` — первоначальный набор иконок, с которого начинали.
