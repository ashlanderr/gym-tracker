# Вход и данные

Как устроены аккаунт, документ и вход через VK ID. Макеты, по которым это
делалось, лежат в истории git (`src/client/pages/SignInMockups`, коммиты
`7ea4fd4`–`bac3458`).

## Принципы

1. **Аккаунт нужен для сохранности, а не для доступа.** Приложение работает
   сразу после установки и без интернета. Вход переносит данные между
   телефонами, позже и подписку.
2. **Без аккаунта данные только на телефоне.** Анонимный документ на сервер
   не ходит: добраться до него смог бы только тот же телефон, где и так лежит
   копия.
3. **У аккаунта один документ, и его id — id пользователя.** Сервер
   синхронизирует документ, только если его id совпадает с неанонимным
   пользователем сессии.
4. **Вход не теряет данные.** Если у телефона и у аккаунта разные документы,
   телефон вливает свой в документ аккаунта. Объединяет клиент, а не сервер:
   у клиента полная локальная копия, даже то, что он не успел отправить.
5. **Выход убирает данные с телефона.** В аккаунте они остаются.
6. **Удаление удаляет всё**: с аккаунтом — и пользователя на сервере, вместе с
   документом и подписками. Этого же требуют RuStore и 152-ФЗ.
7. **Неоднозначное — стираем.** Данные другого аккаунта на телефоне не
   вливаются ни в чей аккаунт. Если человек вышел, не дождавшись
   синхронизации, его предупреждали.
8. **Ничего не всплывает само.** Напоминание о резервной копии — плашка в
   профиле и в настройках.

## Модель

- Телефон: пока нет аккаунта, документ в IndexedDB называется `local`. После
  входа данные лежат под id пользователя (`user/<id>`), `local` стирается.
  Имя базы и говорит, чьи данные на телефоне. Текущий документ живёт в
  `session/store.ts`, `StoreProvider` следует за ним и синхронизирует его,
  только когда это документ вошедшего аккаунта.
- Сервер: строка документа создаётся при первой синхронизации аккаунта,
  `account.delete` удаляет пользователя. Анонимная сессия пока остаётся ради
  проверки подписки RuStore на сервере.
- Имя, аватар и почта кэшируются в `localStorage` (`ACCOUNT`): профиль и
  настройки выглядят одинаково с сетью и без.

## Сценарии

- **Вход, в аккаунте нет тренировок**: данные телефона молча становятся
  данными аккаунта, итоговый экран не нужен. Если профиля нет, онбординг
  вместо первого экрана здоровается по имени.
- **Вход, у аккаунта есть документ, на телефоне тренировок нет** — экран
  «С возвращением»: документ аккаунта загружается, телефонный стирается.
- **Вход, тренировки есть и там, и там** — объединяем без вопросов,
  объединение ничего не удаляет. Профиль (фиксированный id `current`) берём
  из аккаунта, рекорды пересчитываем по обеим историям. Итог показываем
  отдельным экраном, а не тостом: тост поверх главной висел «в никуде».
- **Не удалось загрузить** — «Повторить» или «Начать без аккаунта». Второе
  выходит из аккаунта и оставляет анонимные данные телефона: их нигде больше
  может не быть. Данные другого аккаунта при этом стираются.
- **Прерванный вход** доделывается при следующем старте с сетью.
- **Сервер не узнал токен.** Анонимный — молча новая сессия, данные и так не
  покидали телефон. Токен аккаунта — строка «Данные не сохраняются» и
  «Войти ещё раз» в настройках, синхронизация стоит.
- **На телефоне данные другого аккаунта** (его токен отвергли, и вошёл
  кто-то другой): стираются при входе, в новый аккаунт не вливаются.
- **Выход** всегда разрешён. Если не всё сохранено, кнопка включается через
  5 секунд, как при удалении, и красным написано, что изменения пропадут.
- **Удалить все данные** с аккаунтом требует интернета: без сервера данные
  вернулись бы со следующим входом.

## Решения

- **Пол из VK не берём.** VK отдаёт `sex`, но выигрыш — один тап и только
  когда новый человек сразу нажал «Войти». Пол в VK часто скрыт или
  неправдоподобен, а стартовые веса он меняет почти вдвое. И каждое поле из VK
  надо описывать в политике по 152-ФЗ.
- **Первый экран**: одна кнопка «Начать» и ссылка «Уже есть аккаунт? Войти».
  Вариант с двумя равными карточками отвергнут: новому человеку пришлось бы
  выбирать до первого вопроса.
- **Даты в итогах входа**: «сегодня», «вчера», дальше DD.MM.YYYY. Месяц словом
  с годом («последняя 28 ноября 2025 г.») не помещается в ячейку на телефоне
  шириной 360px и переносится отдельно от своего числа. В профиле даты
  замеров остаются словами — там тесно не бывает.
- **Кнопка входа в профиле приглушённая**, в настройках яркая: профиль
  открывают часто.
