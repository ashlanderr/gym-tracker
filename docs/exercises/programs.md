# Программы и сводный список упражнений

Черновик для отбора упражнений в каталог. Программы здесь — не продуктовые
шаблоны тренировок, а способ ограничить каталог: берём только то, что реально
попадает в слоты трёх самых ходовых схем.

Внутри одной программы упражнения не повторяются: у каждого дня свой набор, а
не A/B-перестановка одного и того же. Между программами повторы есть и это
нормально — базовые движения одни и те же.

Ориентир по залу: DDX, тренажёры Technogym (блочная линейка Selection и
заряжаемая блинами Pure Strength) плюс Matrix, зона свободных весов, машины
Смита, кроссоверы, рамы. Это стартовая точка, а не потолок: каталог описывает
типичный зал и только расширяется. Детали — в [catalog.md](catalog.md).
