# Каталог упражнений с вариациями по инвентарю

Развёрнутый список из 49 якорных упражнений в [programs.md](programs.md).
Каждое движение разложено на вариации, которые реально стоят в зале: штанга,
гантели, Смит, тренажёр с блоком, тренажёр с блинами, кроссовер, свой вес.

Каталог описывает типичный зал, а не конкретный клуб. DDX — только ориентир,
с которого список начался: если тренажёра нет в одном зале, он есть в
соседнем, и строка остаётся.

## Как этим пользоваться

**Вариация = отдельное упражнение.** Не «сгибания рук на скамье Скотта», а
«...со штангой» или «...в тренажёре с блоком»: от этого зависит и калькулятор
блинов, и рекомендация веса. Переносить прогресс между вариациями нельзя.

**Колонка «Вес»** — из чего складывается рабочий вес. Это прямой аналог `load`
и `weight` в `src/client/db/exercises/types.ts`:

| В таблице | `load` / `weight` |
| --- | --- |
| гриф + блины | `{ type: "barbell" }` |
| гриф Смита + блины | `{ type: "barbell" }`, свой вес грифа в настройках |
| 2 гантели / 1 гантель | `{ type: "dumbbell", count: 2 \| 1 }` |
| стек | `{ type: "stack" }` |
| блины, 2 стороны / 1 сторона | `{ type: "plates", sides: 2 \| 1 }` |
| свой вес | `{ type: "none" }` + `weight: { type: "positive" }` |
| свой вес + блины, 1 сторона | `{ type: "plates", sides: 1 }` + `weight: { type: "positive" }` |
| свой вес − противовес | `{ type: "stack" }` + `weight: { type: "negative" }` |

**Кроссовер и односторонние блоки** — вес пишем на одну сторону: именно
столько плиток человек ставит на стеке.

## Правила именования

1. Если у движения есть вариации по инвентарю — инвентарь в названии есть
   всегда, включая базовую: «Жим штанги лёжа», а не «Жим лёжа».
2. Если вариации различаются только хватом в рамках одной мышцы — хват в
   названии у всех: «Тяга верхнего блока к груди широким хватом» /
   «...обратным хватом».
3. Хват не пишем, когда вариация по хвату — это уже другое упражнение на
   другую мышцу: узкий жим лёжа — это трицепс, и он так и называется («Жим
   штанги лёжа узким хватом»), а базовый остаётся «Жим штанги лёжа» без
   уточнения хвата. Иначе каждое второе название разбухает.
4. Слова «рычажный» в названиях нет. «Рычажный» — это про кинематику (рычаг
   вместо троса), а не про нагрузку: бывают тренажёры с рычагом и стеком.
   Человеку у стойки важно другое — куда вешать блины или куда втыкать
   шпильку, поэтому пишем **«с блоком»** (стек плиток) или **«с блинами»**.
5. Уточнение «с блоком / с блинами» ставим там, где в залах встречаются обе
   версии: «Сгибание ног лёжа в тренажёре с блоком» и «...с блинами». Где
   версия одна — не ставим: «Разгибание ног в тренажёре». Появится вторая —
   уточним обе разом.
6. Свой вес — значение по умолчанию, в названии не упоминается. Отягощение
   поверх своего веса — отдельная строка со словом «с отягощением» (пояс,
   блин, гантель между стоп).
7. Тип скамьи пишем, когда он меняет акцент: «на наклонной скамье». Плоская
   скамья по умолчанию не упоминается, и «лёжа» к наклонной скамье не
   приписываем — наклон уже сказал про положение.

Якорные упражнения из программ помечены **★**.

# Чего в каталоге нет и почему

- **Упражнения без измеримой нагрузки.** Отжимания от пола, отжимания от
  скамьи сзади, скручивания лёжа на полу, планка. Приложение про
  прогрессивную нагрузку: если единственный способ прибавить — сделать больше
  повторов, упражнению здесь нечего считать. Подтягивания, брусья,
  гиперэкстензия и подъём ног в висе остаются: у них есть версия с внешним
  весом, а свой вес меняется и учитывается.
- **Резинки и петли.** Нагрузка не выражается в килограммах, калькулятор и
  рекомендации на них не натягиваются.
- **Decline-скамья.** Короткого русского названия нет, движение непопулярное,
  выделенных скамей в залах мало. Низ груди закрывают брусья и дип-машина.
- **Односторонние версии двусторонних упражнений** — подъём на носки в жиме
  ногами на одной ноге и подобное. Это приём, а не отдельное упражнение: если
  плодить односторонний вариант к каждому тренажёру, каталог удвоится.
  Такие вещи заводятся пользователем как кастомное упражнение — и это хороший
  повод сделать кастомные упражнения удобными.
- **Подъём ног в висе с отягощением** (гантель между стоп) — по той же
  причине: встречается, но редко, и закрывается кастомным упражнением.
