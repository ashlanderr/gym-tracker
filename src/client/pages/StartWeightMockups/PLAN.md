# План переноса макетов в приложение

Правила — в [docs/recommendations/README.md](../../../../docs/recommendations/README.md)
(«Первый вес», «Подбор веса», «Разминка», «Профиль», «Каталог») и
[safe-weights.md](../../../../docs/recommendations/safe-weights.md). Здесь
только что и где менять в коде, и то, чего из документов не видно.

Порядок: данные и каталог → расчёты с тестами → экраны и переходы.
Онбординг независим, его можно делать параллельно.

## Данные

- `db/profiles.ts`: `experience: { level, createdAt }`, удалить `anchors`.
- `db/gyms.ts`: отметка, что штангу человек подтвердил. Гантели (`[]`) и
  стеки (нет записи) уже умеют быть «неизвестны», а `defaultGym` кладёт гриф
  20 и блины, и без отметки экран инвентаря штанги никогда не покажется.
- `db/sets.ts`: в `Effort` пятое значение для «Мало».
- Каталог: `safeStart`, `movement`, `base` у плитных, свой тип нагрузки у
  Смита вместо `barbell` с весом каретки на тренажёр.
- `domain/sets.ts` `duplicateSet` копирует подходы вместе с типом. Рабочие
  копировать, разминку вставлять заново по правилу при каждом повторе
  тренировки.

## Расчёты

- Стартовый вес, конфликт с минимумом, замены без известных конфликтов
  (Смит последним) — новые функции в `domain`.
- Разминка: заменить пирамиду `WARM_UP_SETS` и `computeWarmUpSet` в
  `domain/recommendations`.
- Подбор веса — выводится из истории, флага в базе нет.
- `buildRecommendations`: первый подход без истории — стартовый вес, дальше
  шаги подбора. Интерфейс не меняется, параметров не хватает (профиль, вес
  тела, история на несколько выполнений назад).

## Экраны

- `WorkoutFocus/SetView`: строка «Подбор веса · подход N из M», у разминки
  под весом «перед N кг», подписи к изменениям веса в подборе.
- `WorkoutFocus/WeightSheet`: убрать подпись `describeWeights`, на её место —
  строка разминки, высота строки постоянная.
- `WorkoutFocus/RestView`: в подборе оценки «Мало», «Легко», «Норм»,
  «Тяжело»; вне подбора — как сейчас, с «Отказом».
- Новые экраны в тренировке: инвентарь (штанга, гантели, стек), предупреждение,
  «Чем заменить?». Инвентарь сейчас есть только в настройках и по «Мой
  инвентарь» — переиспользовать `WeightsSelector`, если ляжет. Замену
  упражнения взять с его страницы.
- Онбординг: вопрос про стаж с тремя карточками, без шагов якорей, тексты
  «зачем» и `DoneStep` переписать.

## Переходы

- Упражнение без истории: инвентарь, если неизвестен → предупреждение, если
  конфликт → подход.
- «Заменить»: список → выбранное упражнение → его инвентарь, если неизвестен
  → снова проверка конфликта → подход. «Оставить» — подход на минимуме.
- Закрытие шторки веса: вес изменён, сделанных подходов нет, первое
  упражнение группы → вставить разминку, экран на «Разминка 1 из 2». Пока
  шторка открыта, вставлять нельзя: она пишет вес при каждом нажатии.
