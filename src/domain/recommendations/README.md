# Вес следующей тренировки

## Принцип

Подсказки в подходах — это план. Приложение рекомендует только понятную часть
двойной прогрессии: повысить, оставить или снизить вес по повторам. Вводить
можно любой вес, но подсказка не подстраивается под догадки о том, что имел в
виду человек. Начальный подбор веса и снижение веса посреди тренировки
выбирает человек сам.

Никаких уведомлений и вопросов перед упражнением нет: всё видно в таблице.

## Почему один вес и наказание за выход вниз

По исследованиям способ прогрессии почти не влияет на рост, если подходы
близки к отказу. Но без тренера важно не уйти в эголифтинг: держать одинаковую
близость к отказу и не читерить. Для этого нужно владение весом. Верх
диапазона тормозит повтор, низ — показывает, что вес пока не освоен, и на
следующей тренировке вес снижается.

## Рабочий вес

Решают рабочие подходы прошлого раза, разминки не считаются.

1. Рабочий вес — вес последнего подхода. Это последний выбор человека, в
   том числе когда он сам снизил вес из-за усталости.
2. **Снижение.** Последний подход ниже минимума — вес, на котором 1ПМ этого
   подхода даёт минимум повторов. Собирается из инвентаря в сторону меньшей
   нагрузки и не ниже самого лёгкого веса инвентаря. Без веса тела для
   упражнений с весом тела вес неизвестен.
3. **Повышение.** Все подходы с рабочим весом и все на верху диапазона —
   один шаг инвентаря вверх. Подход с другим весом значит, что владение
   весом не доказано.
4. Иначе вес остаётся.

Верх диапазона расширяется до повторов, при которых следующий вес попадает в
низ диапазона по 1ПМ. Поэтому без инвентаря при шаге 2.5 кг на 40 кг верх
диапазона 10–12 — это 15.

## Подсказки в подходах

- Первый рабочий подход — рабочий вес.
- Следующие повторяют вес подхода выше, введённый или выполненный, даже после
  просадки: снижение только на следующей тренировке.
- Повторы — диапазон для веса подхода.
- Разминки считаются от рабочего веса по шаблону.
- Вес неизвестен — в ячейке «?».

## Примеры (диапазон 10–12, без инвентаря)

| Прошлый раз         | Сегодня |
| ------------------- | ------- |
| 40×12, 40×10, 40×10 | 40      |
| 40×15, 40×15, 40×15 | 42.5    |
| 50×10, 40×12, 40×12 | 40      |
| 40×12, 40×10, 40×8  | 37.5    |
| 40×8, 40×7          | 35      |
| 40×12, 40×12, 50×6  | 45      |

## Отложено

- Управляемые подходы: количество и тип подходов под контролем приложения.
  Нужны для дроп-сетов и myo reps, которые не делаются фиксированными
  подходами, и чтобы разминка не стояла после рабочего подхода.
- Рекомендация заменить упражнение, когда снижать некуда.
- Плановый делоад (лёгкая неделя на всю программу). Сниженный вес не должен
  становиться «прошлым разом», для этого нужен признак в данных.
- Долгий перерыв: сейчас вес берётся из прошлого раза, как бы давно он ни был.
