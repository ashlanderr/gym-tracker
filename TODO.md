## Платформа

- Вход через VK ID. Аккаунт остаётся необязательным: приложение работает сразу после установки на локальном ID, логин нужен только чтобы связать устройства и подписку. Проверено на другом проекте (NotiBox), осталось перенести:
  - Провайдер `vk` в Better Auth встроенный, генерик-провайдер не нужен: PKCE и нестандартный для VK `device_id` он делает сам. Включается двумя переменными окружения — `VK_CLIENT_ID` и `VK_CLIENT_SECRET`.
  - Обмен кода на токен идёт через наш сервер, он же держит секрет. Значит в кабинете VK ID нужна только платформа «Веб» с доверенным redirect на домен сервера — регистрировать package name и SHA-1 подписи не нужно, это путь нативного SDK. Release-ключ всё равно понадобится, но уже для публикации в RuStore, а не для входа.
  - Из WebView флоу открывается в системном браузере, обратно в приложение возвращаемся по deep link со своей схемой — её надо завести в манифесте и разрешить в `trustedOrigins`. Это единственная непроверенная часть.
  - Доступ к email нужно включить в настройках приложения VK ID. Без него `getUserInfo` провайдера возвращает `null` и вход падает; с включённым — пользователь либо отдаёт почту, либо не входит вовсе.
  - Анонимный аккаунт присваивается через `onLinkAccount` плагина `anonymous()`: владелец документа меняется одной строкой, id документа остаётся прежним.
- Бизнес-профиль VK ID подтверждён (самозанятый), 60-дневный срок верификации больше не висит.
- Деплой `src/server/` на российский хостинг: Postgres с бэкапами, HTTPS, сборка клиента с боевым `VITE_API_URL`.
- Локальные уведомления: сигнал таймера при заблокированном экране и напоминание о пропущенной тренировке. Именно локальные — серверные пуши не нужны и тянут за собой проблемы с FCM.
- RuStore: биллинг, триал, проверка чека на сервере, кэш статуса подписки с грейс-периодом на оффлайн.
- Публикация: иконки, скриншоты, описание, политика конфиденциальности. Проверить актуальные требования RuStore к аккаунту разработчика.
- Картинок нет у 58 упражнений из 130. Делаются генерацией по одной паре кадров: промпт и измеренные параметры стиля лежат в `media/line-art/README.md`, там же то, на чём модель регулярно ошибается.
- Атрибуция картинок упражнений. Бо́льшая часть каталога нарисована не нами: это набор everkinetic под CC BY-SA 4.0. Лицензия разрешает коммерческое использование, но требует указать автора (Greg Priday, everkinetic), дать ссылку на лицензию и сказать, что картинки изменены — мы инвертировали цвета. ## Техдолг

- Производительность запросов. `queryCollection` делает полный скан коллекции, а `useQueryCollection` подписан на всю коллекцию целиком — любая запись пересчитывает все активные запросы. Лечится индексами в сторе и инкрементальным обновлением по `event.changes.keys`, менять хранилище не нужно.
- `ModalStack`: `popstate`-слушатели не снимаются при размонтировании, условие сравнения по `location.state` хрупкое при быстром двойном «назад». Концепцию (модалка = запись в history) оставить.
- Yjs не трогать до появления платящих пользователей. Апдейты схлопываются в одну строку каждые 100 записей, но история внутри документа всё равно растёт монотонно — позже понадобятся снапшоты и её обрезка.
- README описывает приложение как инструмент совместной работы в реальном времени. Это одиночное приложение, переписать.
- Проверить размер release-сборки с R8. В debug основную массу APK занимает неминифицированный dex.
