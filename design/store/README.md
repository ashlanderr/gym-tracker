Черновик на 29 сентября 2026 года для версии 1.0.0. Требования к полям —
в `docs/rustore/README.md`. Написано только то, что приложение умеет
сейчас: рекомендации весов по истории ещё не готовы, поэтому о них ни
слова (см. `design/branding/README.md` — про ИИ тоже не обещать).

## Полное описание

> Октус — дневник для тех, кто тренируется со штангой, гантелями и в
> тренажёрах. Во время подхода не нужно ничего заполнять: сделал —
> нажал одну кнопку.
>
> С первого дня
> • Несколько вопросов при первом запуске — и у приложения есть
> стартовые веса для базовых упражнений.
> • Регистрация не нужна: дневник работает сразу после установки.
>
> В зале
> • Один экран на подход: упражнение, вес, повторы и цель.
> • Калькулятор блинов показывает, что повесить на каждую сторону грифа.
> • Таймер отдыха между подходами.
> • Каталог из 130 упражнений с похожими упражнениями для замены; у
> большинства есть иллюстрация техники.
>
> После тренировки
> • Итоги: время, объём, подходы и личные рекорды.
> • История и прогресс по каждому упражнению.
> • Уровень силы в жиме, приседе, становой и подтягиваниях.
> • Замеры тела и график веса.
> • Какие мышцы нагружались за последние 30 дней.
>
> Дневник хранится на телефоне и копируется на сервер, поэтому работает
> и без интернета в зале.

## Скриншоты

`screenshots/`, 1080×1920, снимаются скриптом:

```bash
npm run client:dev
npm run store:screenshots
```

Порядок в карточке — по номеру в имени файла: подход, калькулятор
блинов, стартовые веса, вопрос про рабочий подход, пол, рост.
